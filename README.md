# Zac Scott Productions Website

Static website for `zacscottproductions.com`.

## What this is

- Free-hosting friendly site structure
- Homepage plus `Music` and `Movies` sections
- Built as plain HTML/CSS/JS so it can deploy without a paid builder

## Folder structure

- `index.html`: homepage
- `music/index.html`: music section
- `movies/index.html`: movies section
- `assets/styles.css`: site styling
- `assets/app.js`: lightweight animations

## Best free deployment path

1. Put this folder in a GitHub repository.
2. Connect the repo to Cloudflare Pages or GitHub Pages.
3. Point `zacscottproductions.com` from GoDaddy to that host.

## Content hosting reality

- The website itself can be hosted free.
- Large music and movie files usually should not live directly in a free static host.
- Best low-cost path:
  - use YouTube or Vimeo for video playback
  - use SoundCloud or Bandcamp for music playback
  - use this site as the branded presentation layer

## If you want direct hosting later

Use object storage for audio/video files and keep the website static.
